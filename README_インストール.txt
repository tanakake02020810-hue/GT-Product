ケアテクトHB 8商品・インプライム 7商品を削除しました。既存端末の保存済み商品一覧からも対象を削除します。

【インストール方法】
1. ZIPを解凍し、すべてのファイルをGitHub Pagesの公開フォルダにアップロードします。
2. HTTPSの公開URLをChrome/Edgeで開き「アプリとしてインストール」を押します。
3. iPhone/iPadはSafariの共有メニュー→「ホーム画面に追加」を選択します。
※ZIPやローカルHTMLを開いただけではPWAインストールできません。
※初回の読み込みにはネット接続が必要です。
※既存の端末内編集データは基本的に維持されますが、削除対象15商品の編集データは削除されます。事前にバックアップを推奨します。
